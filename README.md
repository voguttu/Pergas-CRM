# Pergas-CRM
Pergas Internal CRM

An internal Customer Relationship Management (CRM) system designed to manage leads, sales activities, and client interactions efficiently.

This CRM is built for performance, scalability, and ease of use, supporting sales teams with real-time lead tracking, status monitoring, and reporting.

---

## 📌 Features

- Lead management (Visited, Quoted, Partially Bought, Bought, Failed, etc.)
- Marketer and client tracking
- Status-based color coding
- Search and filtering
- Sales amount and probability tracking
- Secure session-based authentication
- Optimized for large datasets
- Modular PHP architecture

---

## 🛠️ Tech Stack

- **Backend:** PHP (Procedural / Modular)
- **Database:** MySQL / MariaDB
- **Frontend:** HTML5, CSS3, JavaScript
- **Server:** Apache (cPanel compatible)
- **Version Control:** Git & GitHub
